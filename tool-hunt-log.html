Маршруты поиска

Раскрой нужный, нажми «Копировать» и вставь в чат с ИИ-поисковиком. В квадратных скобках — то, что меняешь под свою задачу.

Приложения (мобильные / десктоп)

Когда нужен инструмент в виде установленного приложения.

Ты — исследователь инструментов. Я ищу приложение (мобильное и/или десктопное) для: [ЗАПРОС — опиши задачу].

Критерии:
1. В приоритете полностью бесплатные приложения. Фримиум/триал показывай только если полностью бесплатных набралось меньше 5 среди всего, что нашёл.
2. Информация должна быть свежей. Если данные старше 6–12 месяцев — отдельно проверь, не изменились ли условия и не заброшено ли приложение.
3. Не останавливайся на первых найденных вариантах. Ищи по разным источникам (обзоры, форумы, Reddit, каталоги приложений, GitHub — поиск и находки там не запрещены, часто там лежат лучшие open-source альтернативы) и продолжай, пока не соберёшь максимально полный список (от 15 вариантов, если ниша позволяет).
4. Для каждого варианта в финальном списке подтверди актуальность минимум из двух независимых источников (например: официальная страница + свежий отзыв/тред за последний год). Если данные расходятся или проект похож на заброшенный — отметь это явно, не выбрасывай молча.

Формат ответа:
— Таблица: Название | Платформа | Цена/лимиты | Статус (бесплатно/фримиум/платно) | Когда обновлялось последний раз | Ссылка
— Затем 2–3 предложения по 3–5 лучшим вариантам — почему именно они.

Не додумывай данные и не обрывай поиск рано.

Ты — исследователь инструментов. Я ищу сайт или онлайн-сервис (SaaS) для: [ЗАПРОС — опиши задачу].

Критерии:
1. В приоритете полностью бесплатные сервисы. Фримиум/подписку с бесплатным тарифом показывай только если полностью бесплатных набралось меньше 5.
2. Проверяй актуальность — тарифы и лимиты у SaaS-сервисов часто меняются. Не бери данные старше 6–12 месяцев без перепроверки.
3. Ищи по нескольким источникам (обзорные статьи, форумы, каталоги вроде AlternativeTo/G2, Reddit, GitHub — если сервис open-source или self-hosted, это тоже плюс) и не останавливайся на первых 2–3 найденных, пока не соберёшь полный список (от 15 вариантов).
4. Для каждого варианта в финальном списке подтверди актуальность минимум из двух независимых источников (официальная страница цен + свежий отзыв). Если что-то похоже на закрытый проект — отметь явно.
5. (если важно) Учитывай доступность в [СТРАНА/РЕГИОН — впиши при необходимости].

Формат ответа:
— Таблица: Название | Что делает | Цена/лимиты | Статус | Когда обновлялось | Ссылка
— 2–3 предложения по 3–5 лучшим вариантам.
Универсальный (для любого запроса)

Когда не хочется думать, какой из шаблонов выбрать.

Ты — исследователь инструментов. Я ищу: [ЗАПРОС — опиши, что нужно: приложение, сайт, сервис, библиотеку, что угодно].

Критерии поиска:
1. Максимально бесплатно — сначала полностью бесплатные варианты. Фримиум/триал показывай, только если полностью бесплатных найдётся меньше 5.
2. Информация — только актуальная. Проверяй, не устарели ли данные (старше 6–12 месяцев требуют перепроверки: не закрылся ли проект, не изменилась ли цена).
3. Ищи по нескольким источникам и запросам (обзоры, форумы, специализированные каталоги, GitHub — поиск там не запрещён и часто даёт лучшие бесплатные находки) и не останавливайся, пока не соберёшь полный самодостаточный список, из которого реально можно выбрать.
4. Для каждого пункта финального списка подтверди актуальность минимум из двух независимых источников. Расхождения или признаки заброшенности — указывай прямо, не молчи.

Формат ответа:
— Таблица сравнения (название, цена/лимиты, статус, дата последнего обновления, ссылка)
— Короткие пояснения по 3–5 лучшим вариантам.

Не додумывай и не обрывай поиск рано.
ИИ-агенты и локальные AI-инструменты

Учитывает совместимость с твоим железом.

Ты — исследователь ИИ-инструментов. Я ищу: [ЗАПРОС — например, агент, локальную модель, инструмент для автоматизации].

Моё железо (если ищешь что-то для локального запуска): RTX 4060 Ti, 8 ГБ VRAM, 32 ГБ RAM. Тяжёлые модели сильно грузят такой ПК — если инструмент требователен к ресурсам, отдельно пометь это и предложи рядом более лёгкую или бесплатную облачную альтернативу (например через OpenRouter или похожие сервисы с бесплатным тарифом).

Критерии:
1. Максимально бесплатно — приоритет open-source и бесплатным API/тарифам. Платное показывай, только если бесплатных вариантов набралось меньше 5.
2. Проверяй актуальность — в мире ИИ всё меняется очень быстро, бери данные не старше нескольких месяцев, где возможно.
3. Ищи по нескольким источникам: GitHub (обязательно — там основная масса open-source агентов и моделей), Hugging Face, Reddit (r/LocalLLaMA и похожие), профильные блоги. Не останавливайся на первых найденных, собирай полный список.
4. Для каждого варианта подтверди актуальность минимум из двух источников (репозиторий + свежее обсуждение/бенчмарк). Если проект заброшен (нет коммитов давно) — отметь явно.

Формат ответа:
— Таблица: Название | Тип (агент/модель/фреймворк) | Требования к железу | Цена/лимиты | Активность проекта | Ссылка
— 2–3 предложения по 3–5 лучшим вариантам с учётом моего железа.
GitHub / open-source репозитории, шаблоны, датасеты

Когда сразу знаешь, что искать нужно среди открытого кода.

Ты — исследователь open-source проектов. Я ищу на GitHub (и смежных площадках вроде GitLab, Hugging Face): [ЗАПРОС — репозиторий, шаблон, датасет, библиотеку].

Критерии:
1. Приоритет — по-настоящему бесплатные и открытые лицензии (MIT, Apache 2.0, GPL и т.п.). Если лицензия ограничивает коммерческое использование — отдельно предупреди.
2. Проверяй «живость» проекта: дата последнего коммита, активность issues/PR, число звёзд как ориентир (но не единственный критерий). Заброшенные форки не включай в топ без пометки.
3. Не бери первый попавшийся репозиторий — ищи по разным запросам/тегам, сравнивай несколько похожих проектов, продолжай пока не соберёшь полный список реальных альтернатив.
4. Для каждого варианта в финальном списке подтверди состояние минимум из двух источников (сам репозиторий + упоминание в статье/треде/сравнении).

Формат ответа:
— Таблица: Название | Что делает | Лицензия | Последний коммит | Звёзды | Ссылка
— 2–3 предложения по 3–5 лучшим вариантам — почему они, для чего лучше подходят.
